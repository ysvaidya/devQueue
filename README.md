# DevQueue

DevQueue is an AI-powered bug triage and issue management platform for software teams.

## Planned Features

- Create and manage software issues
- Categorize issues by type
- Detect potentially duplicate bug reports
- Recommend issue priorities using machine learning
- Allow users to review AI recommendations

## Technology Stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS
- API Gateway: Node.js and Express
- Backend: Python and FastAPI
- Database: PostgreSQL and SQLAlchemy
- Machine Learning: scikit-learn and text embeddings
